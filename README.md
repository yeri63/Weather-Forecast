# Weather Forecast
<div align="center">
  
![Screenshot of BBC World News](https://github.com/yeri63/Weather-Forecast/blob/master/forecast.png)
</div>
7 day weather forecast with hourly Temperatures, Humidity %, Rain Chance %, and Wind Speed for each day of the week. Use the Mode button to change the information displayed, and AM or PM buttons to determine which part of the day to view.
